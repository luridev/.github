# Security Policy

## Supported Versions

Security fixes are generally provided for the latest release.

Older versions may not receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately using GitHub's **Report a vulnerability** feature in the **Security and quality** tab.

Please include:

- A description of the vulnerability.
- The affected package version.
- Steps to reproduce the issue or a proof of concept.
- The potential security impact.

Please do not disclose the vulnerability in public GitHub issues or discussions before it has been reviewed.

## Disclosure

Security reports will be reviewed, and confirmed vulnerabilities will be addressed as appropriate.

If a fix is released, details may be published through a GitHub Security Advisory.
